# USPACE

نموذج أولي عربي لتدوين الأفكار وكتابة Markdown مع حفظ محلي ومساعدة تحريرية اختيارية.

## التشغيل المحلي

1. ثبّت Node.js 20 أو أحدث.
2. افتح الطرفية في مجلد `USPACE` وشغّل `npm run dev`.
3. افتح `http://localhost:4173` على نفس الجهاز.

لا تحتاج اتصالًا بخدمة ذكاء اصطناعي لتجربة المحرر. لا تفتح `index.html` مباشرة من الملفات، لأن التطبيق يحتاج خادمًا محليًا.

## الموجود في هذه النسخة

- مساحات وصفحات وحفظ تلقائي محلي عبر IndexedDB.
- معاينة Markdown، إحصاءات، بحث في الصفحات، واستيراد/تصدير `.md`.
- تنزيل نسخة احتياطية JSON (تصدير فقط؛ الاستعادة من JSON لم تُنفذ بعد).
- تعليمات للمساحة والصفحة؛ مراجعة وتحسين وترتيب عناوين، مع موافقة المستخدم قبل اعتماد النتيجة.
- الترتيب الحرفي يُضيف عناوين فقط قبل أسطر الأصل ويتحقق من الحفاظ على النص الأصلي حرفيًا.
- PWA قابلة للتثبيت على المتصفحات المتوافقة بعد النشر عبر HTTPS.

## إعداد Cloudflare Pages وDeepSeek

1. لا تحفظ أي مفتاح حقيقي في GitHub، حتى لو كان المستودع خاصًا.
2. بعد تثبيت الأدوات (`npm install`) سجّل الدخول إلى Cloudflare باستخدام `npx wrangler login`.
3. أضف المفتاح باستخدام `npx wrangler secret put DEEPSEEK_API_KEY`.
4. أضف رمز وصول شخصيًا قويًا باستخدام `npx wrangler secret put APP_ACCESS_KEY`.
5. انشر بالأمر `npm run deploy` ثم افتح الرابط الذي يمنحك إياه Cloudflare.
6. في نافذة المساعد أدخل **رمز الوصول الشخصي** الذي وضعته في Secret باسم `APP_ACCESS_KEY`، وليس مفتاح DeepSeek نفسه.

يمكنك إنشاء `.dev.vars` من `.dev.vars.example` لتجربة Worker محليًا، لكن لا ترفع الملف للمستودع.

**تنبيه أمان:** هذه نسخة شخصية تجريبية. لم تُنفذ بعد مصادقة مستخدمين أو Rate Limits على Cloudflare أو مزامنة بين الأجهزة. لا تُعرّضها لاستخدام عام قبل إضافة قيود الطلبات والتكاليف.

## الاختبارات

`npm test` لتشغيل الاختبارات، و`npm run build` لبناء ملفات `dist` القابلة للاستضافة. لم يتم اختبار استدعاء DeepSeek فعليًا دون مفاتيح المستخدم.

## النشر من مستودع MMW

- مجلد `uspace/` مستقل عن `local/` و`tilawat/`.
- ملف `.github/workflows/deploy-uspace.yml` ينشر موقع Pages منفصلًا.
- يستعمل Secrets الموجودة في GitHub للنشر: `CLOUDFLARE_API_TOKEN` و`CLOUDFLARE_ACCOUNT_ID`.
- إذا توفرا أيضًا `DEEPSEEK_API_KEY` و`USPACE_ACCESS_KEY` في GitHub Actions Secrets فسيضبطهما سير العمل في مشروع USPACE على Cloudflare Pages باسم `DEEPSEEK_API_KEY` و`APP_ACCESS_KEY` دون نشر قيمهما.
- إذا لم يُضبط مفتاح DeepSeek، يعمل محرر Markdown فقط، وتعيد API خطأ إعداد واضحًا.
- المعاينة الشخصية لا تعادل نظام مصادقة إنتاجيًا؛ لا تُشارك رمز الوصول أو تدعو مستخدمين قبل إضافة Rate Limits وحماية وصول متعددة المستخدمين.
