# USPACE — Personal AI Writing Workspace

مساحة شخصية عربية لحفظ الأفكار وإعادة تنظيمها من دون استبدال النص الأصلي تلقائيًا.

## التشغيل

- Node.js 22 أو أحدث.
- `node uspace/scripts/build.mjs` يبني الواجهة دون حزم خارجية.
- من داخل `uspace` شغّل `npm run preview` لمعاينة الواجهة فقط.
- استدعاء `/api/ai` يحتاج نشر Cloudflare Pages Functions أو Worker؛ خادم المعاينة العادي لا يشغل API.
- الاختبارات: `node --test uspace/tests/*.test.js` و`node --check uspace/dist/assets/app.js`.

## مفتاح DeepSeek الشخصي (BYOK)

1. افتح لوحة «مساعد الكتابة»، وضع مفتاح DeepSeek API في الحقل الجديد.
2. اختر «تفعيل المفتاح» أو ابدأ التحليل مباشرة.
3. يحتفظ USPACE بالمفتاح في ذاكرة الصفحة فقط بصورة افتراضية؛ لا يخزنه في `localStorage` أو قاعدة بيانات الموقع.
4. إن أردت حفظه على الجهاز، افتح «الحفظ المحلي المشفر» واختر عبارة مرور قوية (12 حرفًا على الأقل). تحفظ الخزنة **نصًا مشفرًا فقط** في IndexedDB باستخدام AES-256-GCM، وPBKDF2-SHA256 بعدد 310000 تكرار وsalt عشوائي؛ لا تحفظ عبارة المرور. عند العودة أدخلها لفتح الخزنة.
5. استخدم «قفل» لمسح المفتاح من ذاكرة الصفحة، أو «حذف المفتاح» لمسح النسخة المشفرة والمحلية أيضًا.

**حدود الأمان:** المفتاح لا يظهر في ملفات JavaScript المنشورة ولا في GitHub ولا يكتب في التخزين الخلفي بواسطة كود الموقع. لكن عند الطلب يمر مؤقتًا عبر Cloudflare Pages Function إلى DeepSeek عبر HTTPS؛ وCloudflare والمزود يستطيعان معالجة الطلب وفقًا لسياساتهما. تشفير التخزين المحلي لا يحمي المفتاح من سكربت خبيث يعمل على نفس الصفحة وهي مفتوحة أو من اختراق جهاز المستخدم. لا توجد حماية مطلقة.

**لا تضع مفتاح DeepSeek في GitHub Actions Secrets لتفعيل وضع BYOK.** هذه الأسرار تخص عمليات CI/CD. GitHub Actions يحتاج `CLOUDFLARE_API_TOKEN` و`CLOUDFLARE_ACCOUNT_ID` فقط للنشر. عند استخدام مفتاح خادم بدل BYOK، ضعه مباشرةً في **Cloudflare Pages Secrets** باسم `DEEPSEEK_API_KEY` مع `APP_ACCESS_KEY` لحماية النمط القديم.

## إمكانيات هذا الفرع

- مساحات وصفحات وملاحظات محفوظة في IndexedDB، ونسخ احتياطية JSON للتصدير.
- محرر Markdown مع شريط أولي للعناوين والخط العريض والمائل والقوائم والاقتباس والكود وإدراج الجداول.
- تغيير نوع الخط وحجمه لكل صفحة مع حفظ التفضيل محليًا.
- معاينة Markdown آمنة بنص مهرب، وتنسيق جداول قابل للتمرير.
- AI: ترتيب دون تحريف، تحسين أسلوب، مراجعة، تصحيح إملائي، وصياغة برومبت احترافي.
- مراجعة نتيجة AI قبل اعتمادها وسجل نسخ سابقة.

## المطلوب لاحقًا

هذا **ليس محرر WYSIWYG متكاملًا**: الجداول تُحرّر حاليًا بصيغة Markdown ولا تدعم بعد دمج الخلايا أو السحب لتعديل عرض الأعمدة. كذلك ليس فيه الآن مزامنة أو تسجيل دخول متعدد المستخدمين أو بث Streaming من النموذج. مطلوب مراجعة إضافية للأمن واختبار على أجهزة فعلية قبل اعتماد النسخة إنتاجيًا.

## النشر

النشر الإنتاجي يتم من `main` بواسطة `.github/workflows/deploy-uspace.yml`. لا يُنشر هذا الفرع تلقائيًا. راجع نتائج اختبارات Pull Request قبل الدمج.
