## Source rollout

Live in this release: MP3Quran official API, YouTube public oEmbed metadata, generic direct-audio URLs, and user-local files.

Registry-ready: QuranicAudio, Islamway, TVQuran, Assabile, EveryAyah, SurahQuran, Quran.com, Internet Archive, Mazameer, Yaldosry, SoundCloud, Telegram, TikTok, Instagram.

Treasure/social adapters must use public APIs or publicly accessible metadata only; protected/login/DRM flows are intentionally not bypassed.
